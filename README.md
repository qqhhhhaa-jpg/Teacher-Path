# 🎓 منصة مسار المعلم | Masar Al-Moallem Pro
### المنصة الرقمية الذكية المتكاملة لإعداد وتصميم وتوليد الاختبارات المدرسية والوزارية العراقية

---

## 🌟 أبرز مميزات المنصة:
- 🏛️ **النماذج الوزارية الرسمية المؤتمتة:**
  - نماذج وزارية معتمدة وشاملة لجميع المواد الدراسية (عربي، إنجليزي، رياضيات، فيزياء، كيمياء، إسلامية).
  - تغطية مرحلتي **الصف الثالث المتوسط** و**الصف السادس الإعدادي** (العلمي والأدبي) مع مفاتيح الإجابة النموذجية وتوزيع الدرجات الوزاري (100 درجة).
- 📐 **استوديوهات الرموز والمعادلات التخصصية:**
  - استوديو الرياضيات ومعادلات KaTeX المعرّبة والمؤطرة.
  - استوديو الكيمياء للعناصر والمركبات والتفاعلات.
  - استوديو الفيزياء للقوانين والرموز والمتجهات.
  - استوديو التربية الإسلامية للنصوص والآيات بالرسم العثماني المصحفي والأحاديث الشريفة.
- 🎨 **لوحة سمات وألوان مخصصة (8 ألوان سادة بدون دمج):**
  - أزرق أكاديمي، ذهبي/أصفر فاتح، بنفسجي، جوزي قهوائي، عنبر عسلي، فيروزي، صحراوي دافئ، جويتي أزرق غامق.
- 📄 **تنسيق ومعاينة طباعة مطابقة للامتحانات الرسمية A4:**
  - دعم ترقيم الأسئلة الوزارية، الفروع والخيارات، خطوط الوزارة، وملاحظات الامتحان الرسمية.
  - تصدير فوري إلى PDF وطباعة عالية الدقة.
- ☁️ **المصادقة والتزامن السحابي:**
  - تسجيل الدخول الرسمي عبر Google (GIS OAuth 2.0).
  - مزامنة بنك الأسئلة والامتحانات وحساب المعلم سحابياً.

## 📁 هيكلية وتنظيم ملفات المشروع:
```
├── index.html                   # صفحة الواجهة الرئيسية للمنصة (SPA)
├── css/
│   ├── style.css                # أنماط وتنسيقات المنصة والتصميم المتجاوب
│   └── print.css                # تنسيقات الطباعة الورقية A4 و PDF
├── js/
│   ├── app.js                   # المحرك الرئيسي وإدارة الواجهات والأحداث
│   ├── smart-generator.js       # المولد الذكي والنماذج الوزارية الشاملة
│   ├── islamic-studio.js        # أدوات واستوديو التربية الإسلامية
│   ├── physics-studio.js        # أدوات واستوديو الفيزياء والعلوم
│   ├── question-types.js        # محركات بناء الأسئلة المتنوعة
│   ├── exporter.js              # أدوات تصدير الاختبارات وحفظ الأرشيف
│   └── ai-curriculum-engine.js  # محرك المناهج الدراسية
├── assets/                      # شعارات وأيقونات وزارة التربية والمنصة
├── data/                        # مجلد التخزين المحلي والنسخ الاحتياطي
├── app.py                       # خادم بايثون السحابي المجهز للنشر (Flask WSGI)
├── server_bot.py                # بوت وتطبيق المزامنة والتنبيهات
├── requirements.txt             # متطلبات بايثون للسيرفر
├── Procfile                     # ملف تشغيل السحابة (Render / Railway / Heroku)
├── vercel.json                  # إعدادات النشر المباشر عبر Vercel
├── netlify.toml                 # إعدادات النشر المباشر عبر Netlify
├── رفع_المشروع_إلى_GitHub.bat  # سكربت رفع التحديثات التلقائي إلى GitHub
├── تشغيل_المنصة.bat             # سكربت التشغيل المحلي الفوري
└── دليل_نشر_الموقع_على_الانترنت.md # الدليل الكامل خطوة بخطوة للنشر المجاني
```
