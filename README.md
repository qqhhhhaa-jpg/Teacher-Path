# 🎓 منصة «مُعَلِّم بـرو | Moallem Pro»
### المنصة الرقمية المتكاملة لإعداد وطباعة الاختبارات والأسئلة المدرسية والوزارية بأعلى المواصفات

---

## 🌟 أحدث التحسينات المضافة:

### 1. ✍️ تنسيق الملاحظة الإرشادية (نص بمنتصف الورقة مع خط أسود تحته):
- إزالة أي صناديق أو خلفيات رمادية أو حدود زرقاء جانبية.
- الملاحظة تظهر كـ **نص صريح ومائل في منتصف الصفحة تماماً (Centered)**.
- يوجد **خط أسود صلب ممتد بطول العبارة تحتها مباشرة**، مما يعطي الورقة طابعاً وزارياً رسمياً وأنيقاً مطابقاً للامتحانات الوزارية العراقية والعربية.
- التنسيق مطابق تماماً في كل من المعاينة الحية والطباعة الورقية A4 وPDF.

### 2. 👁️ زر إخفاء وإظهار المعاينة (Toggle Preview):
- تم إضافة زر **«إخفاء المعاينة / إظهار المعاينة»** في الشريط العلوي للموقع.
- **عند إخفاء المعاينة:** تختفي ورقة A4 وتتوسع مساحة العمل للوحة بناء الأسئلة لتشمل كامل الشاشة لتمنحك راحة وتركيزاً كلياً أثناء كتابة وتعديل الأسئلة.
- **عند إظهار المعاينة:** تعود الورقة للظهور جنباً إلى جنب مع مساحة العمل بلمسة واحدة.
- يتم حفظ حالتك المفضلة تلقائياً في المتصفح.

### 3. 🎯 كبسولات مصغرة لأزرار أنواع الأسئلة:
- أزرار مدمجة سريعة (MCQ، صح وخطأ، فراغات، توصيل، مقالي، علل، مسائل).

### 4. 🔄 تصفير ورقة الاختبار بالكامل:
- إمكانية تصفير الورقة ومسح كافة الأسئلة للبدء من الصفر بنقرة زر واحدة.
